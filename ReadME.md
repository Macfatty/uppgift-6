# Uppgift 6 – Testramverk och TDD

## Mocha

[Mocha – officiell webbplats](https://mochajs.org/)

Mocha är ett äldre och ganska enkelt testramverk för JavaScript som påminner om Jest. Det har bland annat stöd för asynkrona tester, vilket innebär att testet kan vänta på exempelvis en förfrågan innan det fortsätter. Mocha har funnits länge och är flexibelt och enkelt att använda.

## Playwright

[Playwright – officiell webbplats](https://playwright.dev/)

Playwright är ett modernare testverktyg med stöd för bland annat UI Mode, där man kan följa tester visuellt. Playwright har även sitt eget testramverk, Playwright Test, men det går också att använda Playwright i tester som körs med exempelvis Mocha.

## TDD – Testdriven utveckling

### Källor

- [Crisp – TDD, Test Driven Development](https://www.crisp.se/gratis-material-och-guider/tdd-test-driven-development)
- [CircleCI – Test-driven development](https://circleci.com/blog/test-driven-development-tdd/)

TDD, testdriven utveckling, innebär att man skriver tester innan själva koden. Metoden består av tre steg: först skriver man ett test som misslyckas, sedan skriver man kod tills testet fungerar och till sist städar och förbättrar man koden utan att testet slutar fungera. TDD gör att tester blir en del av utvecklingen från början och kan hjälpa till att skapa mer pålitlig och välstrukturerad kod.
